# Greek Results Bot

Telegram-бот для проверки результатов экзамена на сайте greek-language.gr.

Бот умеет:
- проверять результат вручную
- запускать периодическую проверку каждые `n` минут
- присылать сообщение, когда результат найден
- хранить несколько кодов для одного пользователя

Пока бот работает на вашем компьютере или сервере, вы можете общаться с ним в Telegram и использовать команды, он будет проверять результаты и присылать их вам, когда они появятся на сайте.

## Требования

- Python 3.10+
- Bash

Бот работает на Linux/MacOS. На Windows можно использовать WSL или поставить Python с официального сайта и попросить ChatGPT помочь с запуском.

## Код активации

Пользователь отправляет боту код в формате:
```text
CENTER-CANDIDATE-SURNAME-SECRET
```

Например:
```text
54321-1234-ANDREOU-the-secret-key
```

Где:
```text
54321     — код экзаменационного центра
1234      — код кандидата
ANDREOU    — фамилия кандидата
the-secret-key — секрет из GREEK_BOT_SECRET в файле .env
```

## Настройка

Скопируйте пример настроек из `.env.example` в `.env`:
```bash
cp .env.example .env
```

Откройте `.env` и заполните:
```env
TELEGRAM_BOT_TOKEN=1234567890:AA...
GREEK_BOT_SECRET=the-secret-key
GREEK_BOT_DB=greek_results_bot.sqlite3
```

`TELEGRAM_BOT_TOKEN` — токен от https://t.me/BotFather.
`GREEK_BOT_SECRET` — секретная часть кода активации, придумайте сами. Она нужна, чтобы никто не мог просто так угадать код активации и начать пользоваться ботом.
`GREEK_BOT_DB` — файл базы данных. Можно оставить как есть.


## Как создать Telegram-бота
1. [Откройте BotFather.](https://t.me/BotFather)
2. Отправьте ему команду:
```text
/newbot
```
3. Введите имя бота, например:
```text
Greek Results Checker
```
4. Введите username бота. Он должен заканчиваться на `bot`, например:
```text
greek_results_checker_bot
```
6. BotFather выдаст токен вида:
```text
1234567890:AA...
```

Запишите этот токен в `TELEGRAM_BOT_TOKEN` в файле `.env`.

## Бот готов к работе!
Запуск, с ботом можно общаться в Telegram:
```bash
bash ./start.sh
```

Остановка, после остановки бот недоступен:
```bash
bash ./stop.sh
```

## Команды бота
После команды `/start` бот пишет:
```text
Введите код активации
```

После ввода хотя бы одного правильного кода пользователю становятся доступны команды.

### `/check`
Проверить все сохранённые коды вручную.

Если результатов нет, бот ответит:
```text
Результатов пока нет
```

### `/run n`

Запустить периодическую проверку раз в `n` минут.

Пример:

```text
/run 30
```

Бот будет проверять результат каждые 30 минут.

Когда результат найден, бот отправляет его и останавливает периодическую проверку.

### `/stop`

Остановить периодическую проверку.

### `/list`

Показать все добавленные коды пользователя.

Пример ответа:

```text
Ваши коды:

1. 35703-4102-SOSNIN
2. 35703-4103-IVANOV
```

### `/remove CODE`

Удалить один код.

Пример:

```text
/remove 35703-4102-SOSNIN
```

### `/remove all`

Удалить все коды пользователя.

Также останавливает периодическую проверку.

## Если сайт greek-language.gr недоступен

При команде `/check` бот покажет ошибку запроса.

При фоновой проверке через `/run n` бот продолжит пробовать дальше. Результат будет отправлен, когда сайт успешно ответит и результат будет найден.
